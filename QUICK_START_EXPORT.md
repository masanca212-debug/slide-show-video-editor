# ⚡ QUICK START - EXPORT VIDEO

Panduan super cepat untuk export video MP4.

---

## 🎯 3 LANGKAH SEDERHANA

### 1️⃣ Siapkan Project

```
✅ Upload gambar (minimal 2-3 gambar)
✅ Set durasi tiap gambar (3-5 detik)
✅ Pilih efek (zoom in/out/none)
✅ Upload musik (optional)
✅ Upload voiceover (optional)
```

### 2️⃣ Preview

```
Klik "Export Video" → Klik "Play" → Lihat preview
```

### 3️⃣ Export

```
Klik tombol "Export Video" (hijau) → Tunggu → Download otomatis!
```

---

## ⏱️ BERAPA LAMA?

| Video | Waktu |
|-------|-------|
| 30 detik | 1-2 menit |
| 1 menit | 2-4 menit |
| 2 menit | 4-8 menit |

---

## ⚙️ SETTING RECOMMENDED

```
✅ Resolution: 1920x1080 (Full HD)
✅ FPS: 30
✅ Duration: 30-120 detik
✅ Browser: Chrome atau Edge
```

---

## 🎨 EFEK TERSEDIA

- **None** - Statis
- **Zoom In** - Ken Burns effect (zoom masuk)
- **Zoom Out** - Zoom keluar pelan-pelan

---

## 🎵 AUDIO

Sistem akan otomatis mix:

1. Background music (semua track)
2. Voiceover (narasi)

---

## 💾 HASIL

- Format: **MP4**
- Quality: **High (CRF 23)**
- Ready upload ke: YouTube, Instagram, TikTok, Facebook

---

## ❗ PENTING

⚠️ **Jangan tutup browser** saat rendering!
⚠️ **Tutup tab lain** untuk free up memory
⚠️ **Sabar menunggu** - proses bisa 2-10 menit

---

## 🐛 MASALAH?

### Export Gagal
→ Refresh & coba lagi

### Terlalu Lama
→ Normal, tunggu sampai selesai

### Browser Freeze
→ Tunggu 30 detik, atau restart browser
